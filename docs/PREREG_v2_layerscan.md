## 1. 口径变更（与历史数字不可比，必须并注）

项目原口径的目标与特征都是**平均绝对收益 MAD**（`mean|r|`），不是已实现波动。
本次改为文献标准的 RV，并同时保留 MAD 口径以便接回旧结论。

- 主口径　`y = log RV_{t+1:t+H}`，其中 `RV = Σ_{i=1..H} r²`（对数收益，日内不跨日）
- 副口径　`y = log MAD_{t+1:t+H}`（= 原 `fvol`，仅用于与历史 ΔR²+0.095 对照）

**历史上所有 ΔR² 数字都是 MAD 口径。** 新口径下的数字不得与之直接比较。

## 2. 视界

`H ∈ {6, 12, 24}` 根 5min bar = **30min / 1h / 2h**。三个全部预注册、全部报告，不允许只报好看的那个。

决策点：每日 bar 0 .. 47−H（未来 H 根必须留在日内，不跨日、不跨午休边界外推）。

## 3. 数据与切分

- 面板 = `out/index_universe.json` 的通过清单（由 `src/screen_indices.py` 机械筛出）
- **universe 只用 train+val (≤2024-06-07) 的数据筛**。用全区间筛会让「哪些指数入选」带上封存段信息

- **本次所有选择、调参、层选取一律只看 val。** test/holdout 不读、不算、不出现在任何表里

## 4. 基线阶梯（Kronos 要打的是其中 val 最强的那个，不是最弱的）

| id | 规格 | 出处 |
|---|---|---|
| B0 | 零拟合 RW：`ŷ = log RV_{t−H+1:t}`，无参数 | — |
| B1 | HAR-RV 高频版：`log RV ~ c + β₁ logRV_{t−11:t} + β₂ logRV_{t−47:t} + β₃ logRV_{t−239:t}` | Corsi 2009 |
| B2 | B1 + 日内节律独热（bar onehot）+ 指数独热 | Andersen-Bollerslev |
| B3 | HARQ：B2 且 β₁ 加 `√RQ` 交互项 | Bollerslev-Patton-Quaedvlieg 2016 |
| B4 | HAR-RS：B2 且把 β₁ 拆成上行/下行半方差 | Barndorff-Nielsen |
| B5 | EWMA / RiskMetrics（λ 在 train 上拟合） | — |

**`B* = argmax_val R²` 定义为"最强基线"。增量一律相对 `B*` 报告，同时附相对 B1 的数字。**

## 5. 处理组

| id | 规格 |
|---|---|
| T1 | `B* + 隐层` 同一个岭回归 |
| T2 | `B*` 的残差 → GatedLinear（rank 32，val 早停）——项目现有方法 |
| T3 | **等权集成**：`½·B*` + `½·(隐层单独岭回归的预测)` |
| T4 | 逐层扫描（见 §6） |

## 6. 逐层扫描的候选计数与采纳判据

Kronos-small 有 **8 个 Transformer block**，d_model 512。扫描位置：

- `L0` = embedding + time_emb + token_drop 的输出（进第一个 block 之前）
- `L1..L8` = 第 k 个 Transformer block 的输出
- `L8n` = `self.norm(L8)`，即 `decode_s1` 实际返回的 context —— **现行生产用的就是这个**
- 每个位置两种池化：`last`（序列最后一个位置，现行做法）与 `mean`（全序列均值池化）

**候选数 = 10 位置 × 2 池化 = 20，乘 3 个视界 = 60 格。这个数字在此写死。**

现行生产用的是 `L8n/last`。

### 采纳一个新层的判据（三条全中才换，写在看到结果之前）

1. 在 **三个视界上都**排进前 2（不允许"只在某一个视界上最好"）
2. 相对 `L8n/last`(现行生产) 的 val ΔR² 优势 **大于 5 个种子的标准差**
3. 在**分指数**口径下，优势在 ≥60% 的指数上同号（不允许被少数指数带动）

任何一条不满足 → 结论是"**最后一层已经够用**"，不换。

> 为什么这么严：20 个候选里挑最好的，单看一格的 val 最优是几乎必然会出现的。
> TimeRep 的第 16/24 层 ≈ 2/3 深度，映射到 8 层约在 L5–L6；若最优层落在这个区间，
> 是对该文献的独立佐证；若落在 L1 或 L8，更可能是选择噪声。

## 7. 必做的零基准与对照（判负库指定的优先陷阱）

判负库对这个形状的研究给出的前五个陷阱是 M4 / E1 / M3 / S6 / M8。本研究不涉及交易，
故 E1、M8 不适用；其余三条必须做：

- **[M4] 最笨的同信息版本**：`nll` + `ent` 两个标量（旧路线）加进 `B*`，看能不能拿到 512 维隐层增量的多少。
  若标量版拿到大部分，则「512 维」这件事本身没有付出代价换来东西。
- **[M3] 只是已有量换名字**：隐层预测对 `B*` 的全部输入正交化后，残差 IC 是否仍显著。
  另：隐层增量与 `log RQ`（已实现四次方差）、日内节律的相关。
- **[S6] 功效正对照 + 安慰剂**：
  - 安慰剂：**按天整体打乱隐层行序**后重跑全链，ΔR² 必须塌到 0 附近（项目历史值 +0.005~0.009）
  - 正对照：把一个已知有效的量（`log RV_{t−H+1:t}` 本身）从基线里抽掉再作为"新特征"喂进去，
    ΔR² 必须很大 —— 证明这条管线**有能力**检出真增量，零结果才可解释

## 8. 主判据（confirmatory）

**一条**，其余全是探索性：

> 在 `H=12`（1h）、`L8n/last`（现行生产位置）、`T2`（残差 + GatedLinear）下，
> 相对最强基线 `B*` 的 **val ΔR² > 0，且 5 种子全正**。

不成立 → 「换成 HAR 基线后隐层增量消失」，这是一个完整的判负结论，按判负库格式入库。

探索性结论（视界比较、层扫描、T1/T2/T3 对照）一律标注为探索性，
并在报告中写明候选数 60，不得以单格 val 最优作为结论。
