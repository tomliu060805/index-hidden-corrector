## 3. 预先写下的判据

### 主判据（一条）

> **test 段 ΔR² > 0，且 CW t > 3。**

不成立 → 「v2 的预报层增量不能外推到样本外」，按判负库格式入库，这条线结束。

### 预先写下的**预期值**（开封后对照，防止事后合理化）

val 段的对应数字是 **ΔR² +0.0148 / CW t 11.06 / QLIKE +1.4%(t=1.61)**
（修完三个数值 bug 之后的最终值；修复前是 +0.0206/10.39/+3.6%）。

- **若 test ΔR² ∈ [+0.010, +0.020]** —— 与 val 一致，结论成立且无衰减
- **若 test ΔR² ∈ [0, +0.010]** —— 衰减但方向对，成立但幅度要按 test 报
- **若 test ΔR² ≤ 0** —— 判负

### 同时报告、但**不作为判据**的量

这些是描述，不是门槛。事先列出以防开封后挑一个好看的当结论：

1. QLIKE 改善与 DM t、逐日为正比例
2. 逐指数分布（为正个数 / 中位 / p10 / p90）

4. 极端波动分位分桶（PIT 同 bar 分位）

6. 四个主力宽基（上证50 / 沪深300 / 中证500 / 中证1000）
