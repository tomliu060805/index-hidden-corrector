## 问题
在**秒级 HAR 基线**之上，L2 盘口独有的量（价差/深度/队列不平衡/OFI/盘口斜率）
对股指期货未来 30s / 60s 的已实现波动有没有增量。

## 为什么先做这个而不是先上模型
判负库 M4「the machinery is not paying for itself」：先建**用同样信息的最笨版本**。
两组都是岭回归，唯一差别是特征集。这个不过线，上任何模型（含 Kronos）都没有意义。

## 判据（先写死）
- ΔR² ≤ +0.005      → 判负，线关闭
- +0.005 < ΔR² ≤ +0.02 → 弱信号，需先排除被慢变量（日内节律/价差水平）带动才继续
- ΔR² > +0.02       → 值得正式立项

## 必须同时跑、不作判据的量
- 基线自身 R²（天花板在哪）
- 按天整体打乱 L2 特征的安慰剂（应塌到 0）
- 逐特征组拆分（哪一组在出力）
- 30s 与 60s 两个视界是否同向

## 变体计数
特征集 2 组 × 视界 2 个 × 品种 3 个（IC/IF/IM）= 12 格，无其他搜索。

## 偏离记录（事后据实补）
- 第一轮 L2 特征做得糙（OFI 是代理、QI 取均值、无报价强度），ΔR²=+0.0053 刚好压在判负线上。
  **补强了一轮**（真 OFI 按队列量变化、报价更新强度、成交笔数、单笔规模、价差/QI/深度的波动），
  变体计数 12 → 28 格。补强后 +0.0092/+0.0098，进入中间带。
- 中间带要求「先排除被慢变量带动」，执行方式 = 把特征拆成**成交流**与**订单簿**两组按序加。
  结论：60-65% 的增量在成交流（L1 或 K 线就有），纯订单簿只剩 +0.0032。
- **加跑了视界扫描**（30s/1min/5min/15min/30min），不在原计划内，理由是要与父项目的视界曲线接上。
  变体计数 28 → 70 格。
- 判据执行：纯订单簿 +0.0032 ≤ +0.005 ⇒ **按预注册判负**。
