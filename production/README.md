# 生产推理包 · 指数隐层修正覆盖层

自包含的实盘推理引擎：每 5 分钟输出 IC/IM 的**目标仓位倍数**（作用于已有净多头敞口）。

## 快速使用

```bash
PY=python   # conda env: alphagen (torch CPU + lightgbm)
export HF_HUB_OFFLINE=1                      # Kronos 权重走本地 HF 缓存

$PY infer.py --date 2026-08-14 --bar 20      # 单个决策点（实盘用，输出 JSON）
$PY infer.py --date 2026-08-14               # 复算某日全天 24 个决策点
$PY infer.py --replay 2026-08-01 2026-08-14  # 区间回放，输出 CSV（对账用）
```

单点耗时 ≈ 数秒（4 线程 CPU），全天 24 点 ≈ 1 分钟。

## 输出字段

```json
{"date":"2026-08-14","bar":20,"time":"11:15",
 "momentum_gate":{"IC":false,"IM":true},
 "positions":{"IC":{"target_raw":1.0,"after_gate":1.0,"w_prev":1.0,
                    "w_final":1.0,"traded":false,
                    "sigma_hat_bp":10.96,"sigma_base_bp":9.82}}}
```

- `w_final` 是**要执行的目标仓位倍数**（1.0 = 基准敞口不加杠杆，最高 3.0）
- `traded=false` 表示落在 δ 死区内，**本次不动手**（正常情况下四天里约三天全天无动作）
- `sigma_hat_bp` 是模型预报的未来 2 小时每 5min 平均波动，`sigma_base_bp` 是基线预报（差值即隐层贡献）

## 决策链（与论文/回测完全一致）

1. 取过去 128 根 5min bar（约 2.5 个交易日）→ 窗口内 z-score → 冻结 Kronos 前向 → 512 维隐层
2. 岭基线（多尺度已实现波动 + 时段独热 + 指数独热）+ GatedLinear 修正 → σ̂（2 小时视界）
3. `w = clip(σ*/σ̂, 1, 3)`
4. **趋势门**：T−1 收盘的 k 日动量 ≤ 0 → w 归 1（IC 看 60 日，IM 看 5 日）
5. **δ 死区**：|w − 当前仓位| < 0.3 不动手
6. 收盘不平仓，持仓过夜（隔夜是收益源，实测日末平回更差）

## 文件

| 文件 | 内容 |
|---|---|
| `infer.py` | 推理引擎（数据加载 → 前向 → 特征 → 仓位） |
| `model_bundle.pt` | 冻结模型包：岭系数、GatedLinear 权重、标准化参数、σ*、全部配置 |
| `replay_*.csv` | 回放输出 |

依赖：权威指数 1min 库（环境变量 `IHC_INDEX_1M`）；本地 HF 缓存的
`NeoQuasar/Kronos-small` 与 Tokenizer；conda 环境 `alphagen`。

## 对账（每次改动后必跑）

生产引擎的预报应与离线 `out/preds_2h.npz` 逐点一致：

```bash
# 见 code/ 目录的对账片段；当前状态：48 点全对，中位相对偏差 4.7e-05
```

偏差来源仅为隐层以 fp16 存储的精度差，`>1e-4` 的点数应为个位数。

## ⚠️ 上线前必读的三条

1. **只用于净多头敞口**（指增期货底仓/多头替代）。空头对冲腿方向相反，实测四格全负
   （IC holdout −1457bp/年，t=−3.4）——绝不可直接套用。
2. **指数独热必须与训练一致**：模型按 300/500/1000 三个指数编码，`train_codes` 已写进
   bundle。曾因只加载 IC/IM 两个指数导致 j 错位、预报偏差 12%——这是本包唯一踩过的坑。
3. **杠杆上限 3 是回测设定**，实测从未触及（峰值 2.08）。实盘应按产品风险预算重设，
   设 2.5 结果几乎不变。
