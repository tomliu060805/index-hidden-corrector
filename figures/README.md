## v1-futures-overlay

**统一口径**: 主力连续(官方映射后移1天), 合约内收益+同合约隔夜, 收盘-收盘含隔夜净值;
成本=平今现实(加仓0.55bp/日内减仓3.77bp/日首减仓与换月按平昨0.55bp)。
背景色带 = 数据切分: 白=训练(≤2023-04) 蓝=验证(≤2024-06) 橙=测试(≤2025-07) 绿=封存段(≤2026-08, 一次性开封)。
配置在 训练+验证 选定后冻结, 测试/封存段无任何再选择。
